# Лабораторна робота №21 — OCP: гнучкі алгоритми розрахунку (Factory/Strategy)

**Варіант 8: Страховий поліс (Авто)**

## Тема та мета

**Тема:** OCP (Open/Closed Principle) — гнучкі алгоритми розрахунку через патерни Factory Method та Strategy.

**Мета:** застосувати принцип відкритості/закритості для створення гнучкої системи розрахунку страхового полісу, забезпечивши легке додавання нових алгоритмів без зміни наявного коду.

## Що таке OCP

**Принцип відкритості/закритості:** класи мають бути *відкриті для розширення*, але *закриті для змін*. Тобто нову поведінку додаємо через новий код (нові класи), а не переписуючи вже робочий.

## Реалізація

Розрахунок вартості страхового полісу залежить від типу покриття. Параметри варіанту 8: **вік водія**, **стаж водіння**, **вартість авто**. Кожен тип полісу застосовує власні коефіцієнти ризику.

### Компоненти

| Компонент | Роль |
|-----------|------|
| `IInsuranceStrategy` | Інтерфейс стратегії: `CalculatePremium(driverAge, drivingExperience, carValue)` |
| `BasicInsurance` | Базовий поліс — тариф 3%, м'які коефіцієнти |
| `ExtendedInsurance` | Розширений — тариф 5% + фіксована доплата 1000 грн |
| `FullCoverage` | Повне покриття (КАСКО) — тариф 8% + 2500 грн |
| `InsuranceStrategyFactory` | Factory Method — `CreateStrategy(string)` повертає потрібну стратегію |
| `InsuranceService` | Контекстний клас — залежить лише від інтерфейсу, стратегія передається в конструктор |

### Коефіцієнти ризику

Кожна стратегія підвищує ризик для водіїв групи ризику:
- вік < 25 років — надбавка за молодого водія;
- вік > 65 років — надбавка за похилий вік (для Extended/Full);
- малий стаж (< 3 або < 5 років залежно від типу) — надбавка за недосвідченість.

## Демонстрація OCP

Додано **4-ту стратегію `CommercialInsurance`** (комерційне використання: тариф 10% + надбавка 5000 грн). Щоб її підключити, знадобилося лише:

1. створити новий клас `CommercialInsurance : IInsuranceStrategy`;
2. додати один рядок у фабрику.

Клас `InsuranceService` **не змінювався жодним чином** — це і є суть OCP: система розширилась без правок наявного коду.

### Файли

- `IInsuranceStrategy.cs` — інтерфейс стратегії.
- `BasicInsurance.cs`, `ExtendedInsurance.cs`, `FullCoverage.cs` — три базові стратегії.
- `CommercialInsurance.cs` — 4-та стратегія (демонстрація розширюваності).
- `InsuranceStrategyFactory.cs` — фабрика (Factory Method).
- `InsuranceService.cs` — контекстний клас.
- `Program.cs` — демонстрація в `Main`.

## Приклад запуску

```
Водій: вік 23, стаж 2 р., авто 500 000 грн

basic      => премія: 28 500,00 грн
extended   => премія: 53 500,00 грн
full       => премія: 94 500,00 грн

=== Демонстрація OCP: додаємо 4-ту стратегію 'commercial' ===
Клас InsuranceService НЕ змінювався — лише додано нову стратегію та запис у фабрику.

commercial => премія: 120 000,00 грн

=== Порівняння для досвідченого водія (вік 40, стаж 15) ===
basic      => премія: 15 000,00 грн
extended   => премія: 26 000,00 грн
full       => премія: 42 500,00 грн
commercial => премія: 55 000,00 грн
```

> Розділювач тисяч/дробової частини залежить від регіональних налаштувань системи.
