# Лабораторна робота №3 — Наслідування

**Варіант 18: Їжа**

## Тема та мета

**Тема:** Наслідування: основи.

**Мета:** закріпити знання про базові класи, похідні класи, модифікатори доступу, використання `base`, поліморфізм у простій формі.

## Опис виконання завдання

Реалізовано ієрархію класів для моделювання страви:

- **`FoodItem`** — базовий абстрактний клас елемента їжі. Містить інкапсульовані поля назви, маси та калорійності на 100 г, конструктор з параметрами, метод `TotalCalories()` для обчислення калорійності порції, абстрактний метод `Category()`, віртуальний метод `GetInfo()` та деструктор.
- **`Fruit`** — похідний клас (фрукт). Додає ознаку солодкості, викликає базовий конструктор через `base(...)`, реалізує `Category()` і перевизначає `GetInfo()`.
- **`Meat`** — похідний клас (мʼясо). Додає вміст білка, викликає базовий конструктор через `base(...)`, реалізує `Category()` і перевизначає `GetInfo()`.

У `Program.cs` створюється колекція `List<FoodItem>`, елементи якої мають базовий тип, але поводяться відповідно до свого фактичного класу (**поліморфізм**). Виконано обчислення загальної калорійності страви та порівняння калорійності за категоріями. Наприкінці продемонстровано роботу **деструктора** через примусове збирання сміття.

### Використані елементи ООП

- базовий клас та два похідні;
- модифікатори доступу `private`, `protected`, `public`;
- конструктори з параметрами та виклик `base(...)`;
- абстрактний метод (`Category`), віртуальний метод (`GetInfo`), перевизначення через `override`;
- деструктор `~FoodItem()`;
- поліморфізм на колекції обʼєктів базового типу.
