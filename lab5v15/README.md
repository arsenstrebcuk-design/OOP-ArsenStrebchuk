# Лабораторна робота №5 — Generics, колекції, LINQ, обробка винятків

**Варіант 15: Пошта / відправлення (PostOffice / Shipment)**

## Тема та мета

**Тема:** Узагальнені типи (Generics), колекції і LINQ, обробка винятків.

**Мета:** навчитися створювати узагальнені класи/методи, працювати з колекціями та LINQ, коректно валідувати вхідні дані і створювати/обробляти винятки.

## Опис виконання завдання

Змодельовано роботу поштового відділення:

- **`Shipment`** — сутність відправлення (трек-номер, напрямок, дати, статус). У конструкторі валідуються дати.
- **`PostOffice`** — поштове відділення. **Композиція:** створює й володіє сховищем відправлень.
- **`IRepository<T>` / `Repository<T>`** — узагальнене сховище з операціями `Add`, `Remove`, `Find`, `All`, `Where`.
- **`CollectionUtils.TopN<T>`** — узагальнений метод, що повертає N найбільших елементів за селектором `Func<T, double>`.
- **Винятки:** `InvalidShipmentDatesException` (дата доставки раніше відправлення) та `NotFoundException` (елемент не знайдено).

### Обчислення (LINQ / колекції)

- середній термін доставки (серед доставлених);
- частка втрачених/пошкоджених відправлень;
- топ-напрямки за кількістю відправлень (через узагальнений `TopN`).

### Використані елементи

- узагальнений клас `Repository<T>` та узагальнений метод `TopN<T>`;
- композиція `PostOffice` → сховище `Shipment`;
- LINQ (`Where`, `GroupBy`, `Average`, `OrderByDescending`, `Take`);
- власні винятки: валідація, кидання, обробка через `try-catch`.

## Приклад запуску

```
Відділення: Відділення №1
Усього відправлень: 6

Середній термін доставки: 2,5 дн.
Втрачено/пошкоджено: 33,3%

Топ-напрямки:
  Київ — 3 відпр.
  Львів — 2 відпр.
  Одеса — 1 відпр.

=== Обробка винятків ===
Помилка дат: Відправлення A007: дата доставки раніше дати відправлення.
Помилка пошуку: Елемент не знайдено у сховищі.
```

> Розділювач дробової частини (`,` або `.`) залежить від регіональних налаштувань системи.
