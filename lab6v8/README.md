# Лабораторна робота №6 — Лямбда-вирази, анонімні функції та делегати

**Варіант 8**

## Тема та мета

**Тема:** делегати, події, анонімні методи, лямбда-вирази, вбудовані делегати `Func<>`, `Action<>`, `Predicate<>`.

**Мета:** закріпити знання про делегати; навчитися використовувати анонімні методи, лямбда-вирази і вбудовані делегати; отримати практичний досвід застосування лямбд у колекціях і LINQ-операціях.

## Опис виконання завдання

Реалізовано згідно з варіантом 8:

- **`Func<int, int, bool>`** — перевірка чисел (`IsDivisible` — чи ділиться перше на друге);
- **`Action<List<int>>`** — друк списку в консоль (`PrintList`);
- **`Predicate<int>`** — видалення непотрібних елементів (`IsOdd` через `RemoveAll`).

### Файли

- **`Operation.cs`** — власний делегат `Operation` для арифметичних/логічних операцій.
- **`NumberService.cs`** — сервіс з вбудованими делегатами `Func`, `Action`, `Predicate`.
- **`LinqProcessor.cs`** — обробка колекції через LINQ (`Where`, `Select`, `OrderBy`, `Aggregate`).
- **`Program.cs`** — демонстрація роботи в `Main` (вивід у консоль).

### Використані елементи

- власний делегат `Operation` + анонімний метод (`delegate {...}`) + лямбда;
- вбудовані делегати `Func<>`, `Action<>`, `Predicate<>`;
- LINQ: `Where`, `Select`, `OrderBy`, `Aggregate`;
- **бонус:** комбіновані (multicast) делегати — кілька `Action<string>` в одному.
